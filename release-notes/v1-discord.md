## DynamicMaps-zzap--bootleg- v1

**- 새 지도 6종(쇄빙선 포함), 연구소 비밀 연구실, 한국어 지도, 미니맵 끊김 줄이기**

■ 바뀐 것
- 새 지도: 터미널, 인터체인지 리워크, 등대 리워크, 연구소 리워크, 공장 클래식. 지명, 탈출구, 이동 지점, 잠긴 문, 스위치까지 다 들어 있음 (메뉴 지도 화면에서 확인, 레이드 안은 아직)
- 연구소: 잘려 있던 1층 비밀 연구실 추가(원래·리워크 지도 둘 다), 리워크 2층 보일러실 위 사무실은 "연구소 (리워크)"에서
- 쇄빙선도 같은 zip에 포함 (14층, 잠긴 문 12개, 헬기 탈출)
- 리워크 맵 모드를 깔았으면 리워크 지도, 아니면 원래 지도를 알아서 고름
- 한국어 지도: 지명, 탈출구, 문, 스위치, 층 이름까지. F12 "언어" 자동이면 게임 언어를 따라감 (영어 게임이면 지도도 영어)
- 다른 한국어 패치가 지도 글자를 영어로 되돌리던 문제 해결 (이 모드 자체 번역 사용)
- 미니맵 켰을 때 끊김 줄임: 같은 층이면 다시 계산 안 함, 확대 끝난 뒤 한 번만 저장 (레이드 측정은 아직)
- 새 지도에 지뢰 지역(빨강), 저격 구역(주황 빗금), 못 가는 구역(어둡게) 표시. 게임 맵 안의 실제 위치, 등대·인터체인지 리워크는 원래 지도 바탕에 바뀐 곳만 반듯하게

■ 설치
- DynamicMaps-zzap--bootleg--v1.zip 풀어서 SPT 폴더에 덮어쓰기 (설정 유지)

■ 주의
- DynamicMaps-Extended랑 같이 깔면 안 됨, 하나만
- 영어로 보면 문 많은 지도는 전체 화면에서 글자가 겹침, 확대하면 풀림
