## DynamicMaps-zzap--bootleg- v1

**- 6 new maps (Icebreaker included), Korean map texts, less minimap stutter**

■ Changes
- New maps: Terminal, Interchange rework, Lighthouse rework, Labs rework, Factory Classic. Labels, extracts, transits, locked doors and switches included (checked on the out-of-raid map screen, not yet in raid)
- Icebreaker is in the same zip (14 decks, 12 locked doors, helicopter exfil)
- Picks the rework map when a Manimal backport / MapVariants runs it, the original map otherwise
- F12 "Language": Auto follows the game language, so an English game shows English maps
- Minimap: no recalculation on the same floor, zoom saved once after you stop (not measured in raid yet)
- Multi-floor maps show doors of other floors faded, door names on hover only

■ Install
- Extract DynamicMaps-zzap--bootleg--v1.zip into your SPT folder (settings kept)

■ Note
- Do not install together with DynamicMaps-Extended, use one
