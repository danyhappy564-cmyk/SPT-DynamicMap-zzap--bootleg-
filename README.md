# SPT-DynamicMap-zzap--bootleg-

SPT 4.1용 [DynamicMaps](https://github.com/mpstark/SPT-DynamicMaps) 수정판입니다. 새 지도(터미널·인터체인지 리워크·등대 리워크·연구소 리워크·공장 클래식, 쇄빙선은 별도 애드온), 한국어 지도·F12, 원본/백포트 지도 자동 선택, 미니맵 끊김 줄이기를 넣었습니다.
An edited build of DynamicMaps for SPT 4.1: new maps, Korean texts, original/backport map pick, less minimap stutter.

- **DynamicMaps-Extended와 같이 설치하지 마세요**(같은 모드를 고친 다른 판). / Do not install together with DynamicMaps-Extended.
- 설치: 릴리즈 zip을 SPT 폴더에 풀어 덮어쓰기. / Install: extract the release zip into your SPT folder.
- 원본 기능 설명: [`Plugin/README.md`](Plugin/README.md)
