# 이 판에서 고친 점 (ZZAP)

원본 Shebuka(tarkov.dev) Labs 그림을 고쳤습니다. 원본과 같은 CC BY-NC-SA 4.0입니다(Shebuka-LICENSE.md).

- 지도 범위를 남동쪽으로 넓혔습니다(게임 x -96 → -78, z -441 → -449). 기존 그림은 그대로 두고 옮기기만 했습니다.
- 1층에 비밀 연구실(Secret Lab)을 더했습니다. 설치된 게임의 원본 연구소 씬(Laboratory_Medical_corridor_floor_1) 충돌 메시에서 바닥(높이 0)과 벽(1.3m 단면)을 직접 뽑아 반듯하게 다듬은 것입니다. 가구는 그리지 않았습니다.
- 의료 구역 복도 끝 벽을 터서 비밀 연구실로 가는 통로를 이었습니다.
- 비밀 연구실과 Manimal 사무실(리워크 2층)을 직각 위주로 다시 정리했습니다. 벽 요철·짧은 토막을 직선으로 합쳤고, 문은 게임 문 충돌체 자리의 벽 틈에 맞춘 사각형입니다. 밀폐문 두 곳(복도 끝·연구실 입구)을 표시했습니다.
- 네 층 그림에서 Unity가 읽지 못하는 CSS 그림자(class="shadow")를 뺐습니다. 도형은 바뀌지 않았습니다.
